# Automatic latest videos and Shorts

- The site shows the six most recent public **long-form videos** from [YouTube's official Videos tab](https://www.youtube.com/@sirasterthecat/videos), in a one-column list.
- Separately, the six most recent public **Shorts** come from the [official Shorts tab](https://www.youtube.com/@sirasterthecat/shorts), using portrait thumbnails in their own gallery. Classification is based on the channel tabs, **not duration or guesswork**.
- The first long-form item is the newest. The current cartridge-based homepage does not include a separate featured-video panel; legacy featured-video rendering code is dormant until a future layout decision. Every displayed item opens its corresponding official YouTube page.
- The public GitHub Actions workflow requests updates every 15 minutes, staggered at minutes 7, 22, 37 and 52. It retries transient failures up to three times. This reduces opportunities for stale data but GitHub can still delay or skip scheduled runs; there is **no guaranteed 15- or 30-minute SLA**. `workflow_dispatch` remains available for manual refresh. Visitors recheck JSON every five minutes while viewing the site.
- The updater uses `yt-dlp` to read public channel tabs, verifies the canonical channel ID, supplements known publish dates from YouTube's Atom feed, and preserves previously verified dates. If either tab cannot be read, the workflow fails safely and the previous data remains in place. The current-series cartridge identifies the newest public long-form title ending in a game episode or finale marker, then matches that game name to an eligible playlist from the official Playlists tab; it does **not** treat playlist-tab ordering as recency. If the newest identified game lacks a corresponding playable playlist or extraction fails, the last verified cartridge stays in place. Titles that lack an episode marker cannot establish a new series automatically.
- Older uploads outside the Atom feed's recent window may not expose an exact date. The interface does **not** invent one. `updatedAt` and the site's “Updated” label report the last changed feed contents, not the time of the last successful check. When titles or dates change for the same IDs, the client now re-renders those records without a page reload.
- Muted hover (650ms) and mobile viewing-dwell (1900ms) previews use embedded YouTube media. Mobile autoplay is device/browser-dependent.
- Twitch embeds remain unchanged: the official Twitch Player reports online/offline events while the page is open, but status is not guaranteed on every network or as an external push notification.
- No YouTube API credentials or paid proxy services are required. `yt-dlp` is pinned in the public workflow and should be reviewed/updated if YouTube changes its tab format.
