NINTENDO 64 GAME DEVELOPMENT · PROJECT SPOTLIGHT

Facet✧

From your first triangle to a playable N64 game.

Facet is an all-in-one Nintendo 64 game-development environment in the making. Designed specifically for N64 hardware, it aims to combine triangle-first 3D modeling, intelligent texture workflows, a high-quality music condenser, an integrated game-building and testing engine, and extensible plugin support. The goal is to give creators everything they need to build a complete N64 game in one place.

WHAT'S TAKING SHAPE

Where the focus is.

01 / FOCUS AREAS

One integrated workspace for the complete Nintendo 64 creation process, from building models and preparing textures to developing music, assembling gameplay and testing the finished game. These are planned capabilities, not a public feature list.

01 / MODEL

Triangle-first modeling

N64-specific modeling built around the triangles that define the console's 3D geometry, with direct control over low-poly game assets.

02 / TEXTURE

Smart texture workflow

Plan, organize and prepare textures within the same development environment, with Nintendo 64 hardware constraints in mind.

03 / MUSIC

High-quality music condenser

A dedicated music condenser is planned to bring music preparation into the same workflow as the rest of an N64 game project.

04 / BUILD

Integrated game-building engine

Bring models, textures, music and gameplay together with an engine designed for creating complete Nintendo 64 games.

05 / TEST

Build and test

Test the game being assembled and iterate without juggling a disconnected collection of development applications.

06 / EXTEND

Plugin support

Planned plugin support will make room for additional community tools, new capabilities and customized development workflows.

THE IDEA BEHIND IT

An entire Nintendo 64 workflow in one place.

N64 development spans much more than modeling. Facet's goal is to connect triangle-first geometry, smart texture preparation, music, gameplay assembly and testing from start to finish inside a single extensible application. This is an ambitious development direction, not a claim that the complete toolchain is available today.

DEVELOPMENT NOTES

Still on the workbench.

  • Built specifically for Nintendo 64 game creation—not simply a general-purpose low-poly modeler.
  • Modeling, texturing, music condensation, game construction, testing and plugin support are all on the planned roadmap.
  • Free and open-source distribution is planned, but no public build or source-code release has been announced.
  • Facet is a working name; final capabilities and release timing may change.
