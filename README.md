# SirAsterTheCat — Public Website
The official public deployment copy of the creator website. Source development and review are maintained privately.

**Homepage**: https://sirasterthecat-png.github.io/

This page uses Charlie's starry-night, Aster-color glass design, original Aster artwork, and static HTML/CSS/JavaScript; no generated character art, trackers, frameworks, accounts, or backend.

**Hosting:** GitHub Pages → Settings → Pages → Deploy from a branch → main → root.

**Launch assets required:** Upload the unchanged `assets/SirAsterCompressed.png` and `assets/AsterHappy.PNG` before enabling Pages. Do not publish imagery without confirming appropriate artist permissions/attribution.

Improve later: replace channel-navigation panels with verified real thumbnails and specific video links; add credited artwork and more verified platforms when available.
